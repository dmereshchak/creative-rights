# CreativeRights — лендинг для музыкантов

Сайт: https://creativerights.ru/ (Vercel, проект `creativerights`; публикуется сам при пуше в `main`).

Лендинг теста спроса: четыре карточки услуг, каждая кнопка открывает форму заявки и отмечает цель в Яндекс Метрике. Заявки приходят в Яндекс Формы, дальше команда пишет человеку, выставляет счёт и делает работу (ИИ-черновик + проверка юриста).

## Настройки — `src/lib/config.ts`

### 1. Яндекс Форма для заявок

Заявки собираются в Яндекс Формах: данные хранятся в России (ч. 5 ст. 18 152-ФЗ). Форма открывается во всплывающем окне сайта.

- `YANDEX_FORM.id` — из ссылки `https://forms.yandex.ru/u/<id>/`.
- В форме три скрытых вопроса с идентификаторами `offer`, `source`, `utm`: сайт подставляет в них выбранную услугу, кнопку и UTM-метки.
- В форме два отдельных чекбокса: ознакомление с политикой и согласие на обработку данных (тексты — `content/pd-notes.md`).
- Ответы смотреть в forms.yandex.ru → форма → «Ответы»; там же включаются уведомления на почту.

### 2. Яндекс Метрика

`YM_ID` — номер счётчика. Цели (тип «JavaScript-событие»):

| Цель | Когда |
|---|---|
| `offer_contract_review`, `offer_contract_draft`, `offer_release_pack`, `offer_release_full`, `offer_sub_personal`, `offer_sub_studio` | Клик по кнопке карточки в «Услуги и цены» (Г-3, Г-4) |
| `cta_hero`, `cta_header`, `cta_faq` | Кнопки «Запросить консультацию» |
| Отправка формы | Цель на стороне Яндекс Форм (настройки формы → Метрика) |

### 3. Контакты

`CONTACT_EMAIL` — рабочая почта (сейчас `creativerights@mail.ru`, проверьте, что она существует). `TELEGRAM_CONTACT_URL` — куда писать напрямую.

### 4. Политика и согласие

`content/privacy.md` и `content/consent.md` — тексты документов, страницы `/privacy` и `/consent`. Плейсхолдеры `[ФИО ОПЕРАТОРА]` и т. п. заполняет и проверяет Артём.

## Лента

Каждый день в 9:00 задача Claude «CreativeRights — 10 правовых изменений для музыкантов» кладёт подборку в `../../Лента/ГГГГ-ММ-ДД.md` и черновик `…json`. На сайт ничего не уходит само. Чтобы опубликовать, скажите Claude «опубликуй ленту за ДД.ММ»: пункты переносятся в `content/feed.json`, сайт пересобирается и пушится. Пустой `feed.json` — блок ленты на сайте скрыт.

## Тема

Светлая и тёмная, переключатель в шапке; по умолчанию — как в системе. Цвета — переменные в `src/app/globals.css`.

## Запуск у себя

```bash
npm ci
npm run dev
```

Сборка: `npx next build`. Если папка лежит по пути с кириллицей (как `Код/` в iCloud), Turbopack падает — используйте `npx next build --webpack`. На GitHub сборка идёт без этой проблемы.

`node_modules` и `.next` — ссылки на папки `*.nosync`, чтобы iCloud их не синхронизировал.
